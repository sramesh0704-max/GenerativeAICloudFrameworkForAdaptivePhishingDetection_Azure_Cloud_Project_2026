# Generative AI Cloud Framework for Adaptive Phishing Detection

## Project Overview

This project develops a cloud-based phishing detection system using Microsoft Azure and Generative AI.

## Objectives

- Detect phishing emails and URLs
- Improve detection accuracy using Azure Machine Learning
- Use Azure OpenAI for phishing analysis
- Store data securely in Azure
- Provide real-time monitoring

## Azure Services

- Azure App Service
- Azure Blob Storage
- Azure Machine Learning
- Azure OpenAI Service
- Azure SQL Database
- Azure Monitor
- Microsoft Defender for Cloud

## Datasets

- PhishTank
- Tranco Top Sites
- Enron Email Dataset
- Phishing Email Dataset
